# TaskFlow - Gerenciador de Tarefas Web

Aplicação web desenvolvida como exercício prático de desenvolvimento web utilizando apenas **HTML5**, **CSS3** e **JavaScript puro**, com persistência local via `localStorage`[cite: 1, 2].

## 🚀 Funcionalidades Obrigatórias
* **Dashboard:** Acompanhamento em tempo real do total de tarefas, pendentes, em andamento e concluídas[cite: 2].
* **Cadastro e Edição:** Registro de título, descrição, prioridade (baixa, média ou alta) e prazo[cite: 2].
* **Quadro Kanban:** Organização visual das atividades nas colunas *A Fazer*, *Em Andamento* e *Concluídas*[cite: 2].
* **Gerenciamento Completo:** Alteração de status diretamente nos cartões, edição e exclusão de tarefas[cite: 2].
* **Pesquisa e Filtros Simultâneos:** Busca por texto no título/descrição e filtros combinados por prioridade e status[cite: 2, 4].
* **Persistência Local (`localStorage`):** Os dados são salvos diretamente no navegador, mantendo as informações ao atualizar ou reabrir a página[cite: 2].

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Estruturação)[cite: 2]
* **CSS3** (Estilização e Design Responsivo)[cite: 2]
* **JavaScript** (Lógica, manipulação do DOM e eventos)[cite: 2]
* **LocalStorage** (Armazenamento de dados no browser)[cite: 2]
* **VS Code** (Ambiente de desenvolvimento)[cite: 1, 2]

## 📥 Como Executar o Projeto
1. Faça o download ou clone este repositório em sua máquina.
2. Abra a pasta do projeto no **VS Code**.
3. Dê um duplo clique no arquivo **`index.html`** para abri-lo diretamente em qualquer navegador de internet (Google Chrome, Edge, Firefox, etc.).
4. Pronto! O sistema já estará funcional para uso.
